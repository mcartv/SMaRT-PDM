SMaRT-PDM Document Review Export Fix v2

ROOT CAUSE
==========
applicationService.js ends with an explicit:

  module.exports = {
      ...
  };

The earlier hotfix added:

  exports.saveApplicationDocumentReview = async ...

but the final module.exports object did NOT include that function.

Therefore applicationController received an object where:

  applicationService.saveApplicationDocumentReview === undefined

and the runtime produced:

  applicationService.saveApplicationDocumentReview is not a function

THIS V2 FIX
===========
- Ensures the implementation exists.
- Adds the function to the FINAL module.exports object.
- Preserves CRLF/LF line endings.
- No SQL.
- No dependency changes.

INSTALL
=======
Extract into:
  D:\projects\SMaRT-PDM

From repo root:
  node SMaRT-PDM_Document_Review_Export_Fix_v2\fix-export.js

RESTART BACKEND
===============
In the Admin backend terminal:
  Ctrl+C

Then:
  cd D:\projects\SMaRT-PDM\admin\backend
  npm start

VERIFY
======
Open a SECOND terminal:

  cd D:\projects\SMaRT-PDM\admin\backend
  node -e "require('dotenv').config(); const s=require('./services/applicationService'); console.log(typeof s.saveApplicationDocumentReview)"

Expected:
  function

Only after it prints "function", retry Request Re-upload in the browser.
