# Scanned document preview

`reference.png` was generated with the built-in imagegen tool as a design reference. The application displays authenticated original scans, never this fictional sample.

Prompt: Use case: ui-mockup. Create a compact desktop admin document OCR review design reference, with two side-by-side cards titled GRADE REPORT OCR and INDIGENCY OCR. Each card has a large rounded scan image preview above extracted fields, restrained warm white background, stone borders, teal accents. The photographed paper previews must be clearly fictional, marked SAMPLE, with no real personal data. Grade report paper has a small grades table; indigency paper has a certificate heading and generic paragraph. Preview shows full page without cropping. Small caption Captured document. Loading and unavailable states represented as small notes underneath the cards. This is a design reference for implementation, not an actual applicant document.
